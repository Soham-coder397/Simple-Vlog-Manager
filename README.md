# Simple Blog Manager
## Features

### User Side
- View latest blogs on the homepage
- View all published blogs
- Responsive blog cards
- Create new blog posts
- Edit existing blogs
- Delete blogs
- Upload featured images
- Responsive navigation menu
- Success popup after publishing a blog

### Blog Management

- Add new blog
- Update blog details
- Delete blog
- Store blogs in JSON
- Upload and manage blog images

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript (ES6)

### Backend
- Node.js
- Express.js

### Packages
- Multer
- CORS
- File System (fs)
- Path
- CLI Table

## Database
Database Type: JSON File
File Used:
- blogs.json

Uploaded Images:
- public/uploads/
